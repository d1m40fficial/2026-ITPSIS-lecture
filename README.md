## Основа проекта

Курс построен на материалах и шаблоне [OlgaKraven](https://github.com/OlgaKraven) — прежде всего на лекционном движке
[2026-lecture-shablone](https://github.com/OlgaKraven/2026-lecture-shablone) (коммит
[aba617d](https://github.com/OlgaKraven/2026-lecture-shablone/tree/aba617d886eb33194e5c1283049f23a9d4452464)),
который распространяется как `@olgakraven/lecture-engine`. Оформление каталога и лекций, вёрстка слайдов,
инфографика, режим преподавателя и печатная версия — из этого шаблона. Локальные изменения движка и
их происхождение зафиксированы в `vendor/README.md` и `vendor/patches/`.

## Содержание

Редакция 2026-09-12-itil-4: 15 лекций для семестров 7 и 8, 120 исходных вопросов, 1663 слайда, 480 заданий.
Сохранены теория и примеры ITIL 4, с отдельным обозначением Version 5. Числа CampusHelp — учебные условия.

После титула идёт карта «Вопросы темы»: она автоматически собирает заголовки восьми разделителей,
в две колонки на компьютере и одну на телефоне. Заключительный слайд — вопросы аудитории.
Библиография и материалы вынесены из лекций в общий список курса; указание семестра на слайдах убрано.
Справка с иконками открывается рядом с переключателем темы.

## Доступ по коду и результаты

Лекция открывается кодом преподавателя. Коды хранятся в `config/access-codes.json`, файл не публикуется,
в сборку уходят только SHA-256 хеши. Срок доступа — неделя; мастер-код снимает доступ и зафиксированное ФИО
на устройстве. После самопроверки студент один раз вводит ФИО для этой лекции и получает подписанный
результат: `npm run verify:certificate` проверяет подпись на стороне преподавателя.
Подробности и границы защиты — в [docs/ACCESS_AND_CERTIFICATE.md](docs/ACCESS_AND_CERTIFICATE.md).

## Заметки без ручного импорта

Режим преподавателя открывается панелью на URL вида `?mode=presenter&lecture=<id>&session=<uuid>`: после статуса
«Заметки курса загружены» доступны сценарий, подготовка, запись, вопросы и ответы на каждом слайде. Все 8615 разделов заполнены. Загружается только текущая лекция; комплект не записывается целиком в localStorage.

Опубликованные заметки курса доступны по прямым ссылкам — таково указание автора. Личные изменения сохраняются только в браузере и имеют приоритет. Непустые записи редакции 2026-09-12-itil-2 сохраняются при переходе к новой редакции; её пустые вкладки дополняются. Явное редактирование, включая очистку поля, сохраняется. При ошибке загрузки доступна повторная попытка и ранее сохранённые записи.

«Сохранить заметки» экспортирует текущий доступный комплект с личными правками. «Загрузить заметки» — необязательный импорт резервной копии текущего курса и версии. Перед импортом сохраните собственные изменения. Audience, каталог, обычный просмотр и PDF не загружают файлы заметок; их отображает панель преподавателя.

## Исходники и сборка

Пакет @olgakraven/lecture-engine 0.1.2-itpsis.1 основан на [шаблоне aba617d](https://github.com/OlgaKraven/2026-lecture-shablone/tree/aba617d886eb33194e5c1283049f23a9d4452464) из материалов [OlgaKraven](https://github.com/OlgaKraven). Локальные изменения воспроизводятся через патчи [published-notes.patch](vendor/patches/published-notes.patch) и [access-and-certificate.patch](vendor/patches/access-and-certificate.patch), порядок сборки описан в [vendor/README.md](vendor/README.md).

- public/course.json — производные ученические данные. scripts/compile-course.mjs собирает их из authoring/.
- authoring/teacher-notes.json — канонический опубликованный сценарий. prepare:notes проверяет все слайды и пять вкладок и создаёт public/teacher-notes/*.json.
- docs/guide-content.json и scripts/generate-guide.mjs — визуальная инструкция с иконками исходного шаблона.
- authoring/original-course.json, question-map.json и migration-map.json — исходные вопросы и карта всех 1275 первоначальных слайдов.
- public/assessment.json — публичные ключи автономной учебной самопроверки.
- config/access-codes.json и config/access-codes.txt — коды доступа преподавателя, не публикуются.
- private/ — только локальные материалы, исключённые из Git.

Node.js 22.18+; проверено на Node.js 24.11.1.

```sh
npm ci
npm run dev
npm run compile:content
npm run lint
npm test
npm run spellcheck
npm run build
npx playwright install chrome
npm run test:e2e
npm run preview
```

При изменении содержания обновляйте соответствующие заметки и версию. Сборка блокируется при отсутствующей заметке, пустой вкладке или несовпадении версии. Не добавляйте персональные данные в опубликованный сценарий.

## PDF и проверки

```sh
npm run export:pdf
npm run check:pdf
```

PDF формируются из того же рендерера, по одной странице 16:9 на слайд, без заметок и попыток. PDF_OUTPUT_DIR меняет папку экспорта.
Файлы в public/pdf сделаны до последней правки содержания и не соответствуют текущим 1663 слайдам — перегенерируйте при необходимости.

[Отчёт](reports/QUALITY.md). Полная РПД и утверждённые часы не переданы; 188–200 минут — оценка полного маршрута по заметкам, а не расписание. Физический проектор не испытывался.

GitHub Actions проверяет и публикует dist; базовый путь /2026-ITPSIS-lecture/.
